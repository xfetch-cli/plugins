<h1 align="center">Support</h1>

<p align="center">
  Need help with a plugin? Installation, configuration, platform support, or protocol issues?
</p>

<h2 id="get-help" align="center">Get Help</h2>

<ul>
  <li><b>Issues:</b> <a href="https://github.com/xfetch-cli/plugins/issues">github.com/xfetch-cli/plugins/issues</a></li>
  <li><b>Plugin docs:</b> <a href="./docs/README.md">Developing plugins</a>, <a href="./docs/compatibility.md">Platform compatibility</a></li>
  <li><b>Core docs:</b> <a href="https://github.com/xfetch-cli/xfetch/blob/main/docs/CONFIGURATION.md">xfetch configuration</a> (<code>info_plugins</code>, <code>logo_animation</code>)</li>
  <li><b>Security reports:</b> <a href="mailto:x@xscriptor.com">x@xscriptor.com</a> (private disclosure)</li>
</ul>

<h2 id="before-opening-an-issue" align="center">Before Opening an Issue</h2>

<ul>
  <li>Confirm your platform (Linux/macOS/Windows) and the plugin version.</li>
  <li>Verify the plugin is installed: <code>xfetch plugin list</code>.</li>
  <li>Include the plugin's config block, the raw output (or failure), and reproduction steps.</li>
  <li>Check the <a href="./docs/compatibility.md">compatibility table</a> — not every plugin runs on every OS.</li>
</ul>

<h2 id="response-expectations" align="center">Response Expectations</h2>

<p>
  Maintainers triage reports based on impact and reproducibility. Clear, minimal reproductions are resolved faster.
</p>
